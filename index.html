Private IPv4 ranges

These ranges are for local networks and are not routed on the public internet.

  • 10.0.0.0/810.0.0.0 – 10.255.255.255
  • 172.16.0.0/12172.16.0.0 – 172.31.255.255
  • 192.168.0.0/16192.168.0.0 – 192.168.255.255
#

Classful IPv4 ranges

Legacy classes group addresses by their leading bits. Modern networks use CIDR.

  • Class A1.0.0.0 – 126.255.255.255
  • Class B128.0.0.0 – 191.255.255.255
  • Class C192.0.0.0 – 223.255.255.255
  • Class D224.0.0.0 – 239.255.255.255 · multicast
  • Class E240.0.0.0 – 255.255.255.255 · reserved
↻

Special addresses

Loopback: 127.0.0.0/8 sends traffic back to the local device; 127.0.0.1 is commonly used.

Network address: identifies the subnet and has all host bits set to 0.

Broadcast address: reaches all hosts in an IPv4 subnet and has all host bits set to 1.

⇄

IPv4 versus IPv6

IPv432-bit

About 4.3 billion addresses; dotted decimal, e.g. 192.168.1.10

IPv6128-bit

A vastly larger address space; hexadecimal groups, e.g. 2001:db8::1

i

Remember: for /31 point-to-point links, both addresses are usable as endpoints. A /32 represents one address, so conventional network and broadcast host rules do not apply.
